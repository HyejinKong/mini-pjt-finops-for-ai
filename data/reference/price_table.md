# Bedrock 모델 단가표 (더미)

실제 AWS 가격이 아닌 교육용 더미 단가다. 단위는 USD per 1M tokens 이며 입력과 출력 단가가 따로 있다.
비용 = 입력 토큰 × 입력 단가 / 1,000,000 + 출력 토큰 × 출력 단가 / 1,000,000

| 모델 | 입력 단가 | 출력 단가 |
|---|---|---|
| claude-sonnet | $3.00 | $15.00 |
| claude-haiku | $1.00 | $5.00 |
| nova-pro | $0.80 | $3.20 |
| nova-lite | $0.06 | $0.24 |
